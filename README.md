# Mini Hospital Emergency Management System Using Java Data Structures

## 📌 Project Overview

The **Mini Hospital Emergency Management System** is a Java-based console application designed to manage emergency patient information efficiently using fundamental **Data Structures**.

The system demonstrates how different data structures can be applied to real-world hospital management tasks such as storing patient records, managing emergency queues, recording treatment history, and maintaining patient visit history.

This project was developed as part of a Java Data Structures assignment.

---

## 🎯 Objectives

The main objectives of this project are:

* To implement different data structures using Java.
* To manage emergency patient records efficiently.
* To demonstrate the practical use of **Binary Search Tree, Queue, Stack, and Singly Linked List**.
* To provide a simple menu-driven hospital management system.
* To handle patient information and hospital activities in an organized manner.
* To demonstrate proper Java programming and object-oriented programming concepts.

---

## 🏥 Data Structures Used

### 1. Binary Search Tree (BST) – Patient Records

The Binary Search Tree is used to store and search patient records.

**Operations:**

* Insert patient
* Search patient
* Display patient records
* Traverse the tree

The BST allows patient information to be organized according to the patient ID.

### 2. Queue – Emergency Patient Queue

A Queue is used to manage emergency patients according to the **FIFO (First In, First Out)** principle.

**Operations:**

* Enqueue patient
* Dequeue patient
* Display waiting patients
* Handle an empty queue

### 3. Stack – Treatment History

A Stack is used to maintain patient treatment history using the **LIFO (Last In, First Out)** principle.

**Operations:**

* Add treatment
* Remove the latest treatment
* Display treatment history
* Handle an empty stack

### 4. Singly Linked List – Patient Visit History

A Singly Linked List is used to store previous patient visits.

**Operations:**

* Add visit
* Display visit history
* Maintain visits in sequence

## ▶️ How to Run the Project

1. Download or clone the repository.
2. Open **Eclipse IDE**.
3. Import the project into Eclipse.
4. Open the `HospitalManagementSystem.java` file.
5. Run the program using **Run → Run As → Java Application**.
6. Select the required option from the menu.
7. Enter the required patient information.
8. Use the menu options to manage patient records and hospital activities.
